## 🛠️ 项目结构

```text
.
├── app/                # 网页应用组件
├── assets/             # 静态资源文件 (图片、图标等)
├── mingli/             # 八字命理项目
├── mixin/              # 混合工具页面
├── new-poetry/         # 新诗集项目
├── outfity/            # Outfity 项目
├── poetry/             # 诗集展示项目
├── year/               # 2022-2025 年度总结页面
├── index.html          # 主页入口
├── server.js           # 静态文件服务器 (Node.js)
└── README.md           # 项目说明文档
```

## 💻 本地运行

本项目包含一个简单的 Node.js 静态服务器，方便在本地预览：

1. **环境准备**: 确保已安装 [Node.js](https://nodejs.org/)。
2. **启动服务器**:
   ```bash
   node server.js
   ```
3. **访问页面**: 打开浏览器访问 `http://localhost:8000`。
